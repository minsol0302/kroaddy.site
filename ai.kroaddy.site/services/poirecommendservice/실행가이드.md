## 1. 모델 학습하기

### 전제 조건
- `dfE.csv` 파일이 `app/preprocessed/` 디렉토리에 있어야 합니다.

### 실행 방법

```bash
# 1. 프로젝트 디렉토리로 이동
cd ai.kroaddy.site/services/poirecommendservice

# 2. 가상환경 활성화 (선택사항)
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/Mac
python3 -m venv venv
source venv/bin/activate

# 3. 필요한 패키지 설치
pip install -r requirements.txt
pip install scikit-optimize  # GridSearchCV 최적화를 위해

# 4. 모델 학습 실행
cd app/models
python train_model.py
```

### 실행 결과
- `svd_model_E.pkl` 파일이 `app/models/` 디렉토리에 생성됩니다.
- 콘솔에 학습 과정과 성능 지표가 출력됩니다.

### 예상 출력
```
[1단계] 데이터 로드 및 검증
원본 데이터 크기: (336, 4)
고유 사용자 수: 100
고유 아이템 수: 50
...

[4단계] 하이퍼파라미터 튜닝
최적 하이퍼파라미터 (RMSE 기준):
  RMSE: 0.8234
  파라미터: {'n_factors': 100, 'n_epochs': 50, ...}

[5단계] 최종 모델 학습
모델 학습 완료
...

[7단계] 모델 저장
모델 저장 완료: svd_model_E.pkl
```

## 2. API 서비스 실행하기

### 전제 조건
- `svd_model_E.pkl` 파일이 `app/models/` 디렉토리에 있어야 합니다.
- `dfE.csv` 파일이 `app/preprocessed/` 디렉토리에 있어야 합니다.

### 실행 방법

```bash
# 1. 프로젝트 디렉토리로 이동
cd ai.kroaddy.site/services/poirecommendservice

# 2. 가상환경 활성화 (선택사항)
# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate

# 3. 필요한 패키지 설치 (아직 안 했다면)
pip install -r requirements.txt

# 4. FastAPI 서버 실행
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 서버 접속
- **API 문서**: http://localhost:8000/docs
- **대체 문서**: http://localhost:8000/redoc
- **서버 주소**: http://localhost:8000

### 예상 출력
```

INFO:     Started reloader process
INFO:     Started server process

2024-01-01 12:00:01 - app.model_runner - INFO - [모델 로드 완료] ...
```

### API 테스트

#### 방법 1: 브라우저에서 테스트
1. http://localhost:8000/docs 접속
2. `/recommend` 엔드포인트 클릭
3. "Try it out" 버튼 클릭
4. 요청 본문 입력:
```json
{
  "userID": "e000008",
  "topN": 5
}
```
5. "Execute" 버튼 클릭

#### 방법 2: curl 명령어
```bash
curl -X POST "http://localhost:8000/recommend" \
  -H "Content-Type: application/json" \
  -d '{"userID": "e000008", "topN": 5}'
```

#### 방법 3: Python 코드
```python
import requests

response = requests.post(
    "http://localhost:8000/recommend",
    json={"userID": "e000008", "topN": 5}
)

print(response.json())
```

### 예상 응답
```json

  "userID": "e000008",
  "recommendations": [

    {
      "itemID": "자라섬",
```

## 🔧 문제 해결

### 모델 파일이 없을 때
```
FileNotFoundError: [Errno 2] No such file or directory: 'app/models/svd_model_E.pkl'
```
**해결**: 먼저 `train_model.py`를 실행하여 모델을 학습시켜야 합니다.

### 포트가 이미 사용 중일 때
```
ERROR:    [Errno 48] Address already in use
```
**해결**: 다른 포트 사용
```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8001
```

### 패키지가 설치되지 않을 때
```
ModuleNotFoundError: No module named 'surprise'
```
**해결**: 
```bash
pip install -r requirements.txt
```

## 🚀 프로덕션 배포

프로덕션 환경에서는 `--reload` 옵션을 제거하고 다음과 같이 실행:

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
```

또는 Docker를 사용:
```bash
docker build -t poi-recommend-service .
docker run -p 8000:8000 poi-recommend-service
```
