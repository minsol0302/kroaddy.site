# 모델 학습 로그 확인 가이드

## 📋 로그 저장 위치

모델 학습을 실행하면 로그가 자동으로 저장됩니다:

```
app/models/logs/train_YYYYMMDD_HHMMSS.log
```

예: `app/models/logs/train_20240101_143022.log`

## 🔍 로그 확인 방법

### 1. 학습 실행 후 로그 확인

학습이 완료되면 콘솔에 로그 파일 경로가 표시됩니다:

```
================================================================================
학습 완료!
시작 시간: 2024-01-01 14:30:22
완료 시간: 2024-01-01 14:35:45
소요 시간: 0:05:23
로그 파일: logs/train_20240101_143022.log
================================================================================
```

### 2. 로그 파일 직접 확인

#### Windows (PowerShell)
```powershell
# 최신 로그 파일 확인
Get-ChildItem logs -Filter "train_*.log" | Sort-Object LastWriteTime -Descending | Select-Object -First 1 | Get-Content

# 특정 로그 파일 확인
Get-Content logs/train_20240101_143022.log

# 로그 파일 목록 보기
Get-ChildItem logs -Filter "train_*.log" | Sort-Object LastWriteTime -Descending
```

#### Linux/Mac
```bash
# 최신 로그 파일 확인
ls -t logs/train_*.log | head -1 | xargs cat

# 특정 로그 파일 확인
cat logs/train_20240101_143022.log

# 로그 파일 목록 보기
ls -t logs/train_*.log
```

### 3. 실시간 로그 모니터링 (학습 중)

학습이 진행 중일 때 실시간으로 로그를 확인하려면:

#### Windows (PowerShell)
```powershell
# 다른 터미널에서 실행
Get-Content logs/train_*.log -Wait -Tail 50
```

#### Linux/Mac
```bash
# 다른 터미널에서 실행
tail -f logs/train_*.log
```

## 📊 로그 내용

로그 파일에는 다음 정보가 포함됩니다:

1. **학습 시작 정보**
   - 시작 시간
   - 로그 파일 경로

2. **데이터 로드 및 검증**
   - 데이터 크기
   - 고유 사용자/아이템 수
   - 평점 범위 및 평균

3. **데이터 전처리**
   - 중복 제거 결과
   - SIDO 결측값 처리
   - Cold Start 필터링 결과

4. **하이퍼파라미터 튜닝**
   - 파라미터 그리드
   - 최적 하이퍼파라미터
   - 최적 성능 지표 (RMSE, MAE)

5. **모델 학습**
   - Train/Test set 크기
   - 학습 진행 상황
   - 교차 검증 결과

6. **모델 평가**
   - 테스트셋 RMSE, MAE
   - Recall@5 점수

7. **학습 완료 정보**
   - 완료 시간
   - 소요 시간
   - 로그 파일 경로

## 💡 유용한 팁

### 로그 파일 크기 확인
```powershell
# Windows
Get-ChildItem logs -Filter "train_*.log" | Select-Object Name, @{Name="Size(KB)";Expression={[math]::Round($_.Length/1KB,2)}}

# Linux/Mac
ls -lh logs/train_*.log
```

### 로그에서 특정 키워드 검색
```powershell
# Windows
Select-String -Path "logs/train_*.log" -Pattern "RMSE"

# Linux/Mac
grep "RMSE" logs/train_*.log
```

### 오래된 로그 파일 삭제
```powershell
# Windows - 30일 이상 된 로그 삭제
Get-ChildItem logs -Filter "train_*.log" | Where-Object {$_.LastWriteTime -lt (Get-Date).AddDays(-30)} | Remove-Item

# Linux/Mac - 30일 이상 된 로그 삭제
find logs -name "train_*.log" -mtime +30 -delete
```

## 🔧 문제 해결

### 로그 파일이 생성되지 않는 경우
1. `logs` 디렉토리가 생성되는지 확인
2. 파일 쓰기 권한 확인
3. 디스크 공간 확인

### 로그 파일이 너무 큰 경우
- 로그 파일은 자동으로 타임스탬프별로 분리됩니다
- 오래된 로그는 삭제해도 됩니다

### 로그를 실시간으로 보지 못하는 경우
- 학습 스크립트를 실행한 터미널에서도 로그가 출력됩니다
- 콘솔 출력과 파일 로그는 동일한 내용입니다
