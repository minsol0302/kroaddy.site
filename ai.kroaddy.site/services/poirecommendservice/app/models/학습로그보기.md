# 학습 로그 보는 방법

## 📝 빠른 가이드

### 1단계: 모델 학습 실행

```powershell
# 프로젝트 디렉토리로 이동
cd ai.kroaddy.site\services\poirecommendservice\app\models

# 모델 학습 실행
python train_model.py
```

### 2단계: 로그 확인

학습이 완료되면 콘솔에 로그 파일 경로가 표시됩니다:

```
================================================================================
학습 완료!
로그 파일: logs/train_20240101_143022.log
================================================================================
```

### 3단계: 로그 파일 열기

#### 방법 1: PowerShell에서 확인
```powershell
# 최신 로그 파일 확인
Get-Content logs\train_*.log | Select-Object -Last 100

# 전체 로그 확인
Get-Content logs\train_*.log
```

#### 방법 2: 파일 탐색기에서 확인
1. `app/models/logs/` 폴더로 이동
2. `train_YYYYMMDD_HHMMSS.log` 파일을 메모장이나 VS Code로 열기

#### 방법 3: VS Code에서 확인
```powershell
# VS Code로 로그 파일 열기
code logs\train_*.log
```

## 🔍 실시간 로그 확인 (학습 중)

학습이 진행 중일 때 실시간으로 로그를 보려면:

**다른 PowerShell 창을 열고:**
```powershell
cd ai.kroaddy.site\services\poirecommendservice\app\models
Get-Content logs\train_*.log -Wait -Tail 50
```
